
# ⚡ Smart Power Usage Monitoring System

An IoT-based electrical monitoring project developed using the ESP32 microcontroller.

## 📌 Project Overview

The Smart Power Usage Monitoring System is designed to monitor electrical parameters using sensors connected to an ESP32.

The system uses current and voltage sensors to collect electrical measurements and demonstrates the application of embedded systems and IoT technology.

## 🎯 Project Objectives

- Monitor electrical current.
- Measure electrical voltage.
- Interface sensors with ESP32.
- Develop an embedded monitoring prototype.
- Explore IoT-based energy monitoring.

## 🔧 Hardware Components

| Component | Purpose |
|---|---|
| ESP32 | Main microcontroller |
| ACS712 | Current sensing |
| ZMPT101B | AC voltage sensing |
| LCD Display | Measurement display |

## 💻 Software & Technologies

- Arduino IDE
- Embedded C/C++
- ESP32
- Internet of Things (IoT)

## ⚙️ Working Principle

1. The ACS712 sensor measures electrical current.
2. The ZMPT101B sensor measures AC voltage.
3. The ESP32 reads the sensor signals.
4. The microcontroller processes the readings.
5. Electrical measurements can be displayed through the monitoring interface.
